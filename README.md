# About

Blocks ads, trackers, crash reporting and upsells in the 
[TradingView](https://www.tradingview.com) desktop app (the Debian package).

## Usage

```sh
sudo ./tv-adblock.sh install   # apply the patch
sudo ./tv-adblock.sh revert    # restore the pristine asar
./tv-adblock.sh status         # is it applied?
```
